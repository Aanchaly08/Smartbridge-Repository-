# Lightning App

## Project Name

**AI-Powered Customer Support Ticketing System**

## Overview

A custom **Salesforce Lightning App** was created to provide a centralized workspace for managing and monitoring customer support cases.

## Features

- Easy navigation through the **Salesforce interface**.
- Direct access to **Case records**.
- Integration with **Reports and Dashboards**.
- User-friendly layout designed for **support agents**.

## Components Included

The Lightning App includes the following components:

- **Cases**
- **Reports**
- **Dashboards**
- **Home Page**

## Benefits

The Lightning App provides the following benefits:

- **Simplifies daily support operations**.
- **Improves support team productivity**.
- Provides **quick access to customer support information**.
- Centralizes important support tools within a single workspace.
