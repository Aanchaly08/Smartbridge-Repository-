# Functional Scope

## Project Name

**AI-Powered Customer Support Ticketing System**

## Purpose

The project aims to **automate customer support operations using Salesforce** by efficiently managing and tracking customer support tickets.

## Scope

The system includes the following core functionalities:

- Create and manage **customer support cases**.
- Track **ticket status and priority**.
- Automate **email notifications** using Salesforce Flows.
- Generate **reports** for customer support analysis.
- Provide an **easy-to-use Lightning App interface**.

## Users

The system is designed for the following user roles:

- **Customer Support Agents**
- **Support Managers**
- **Salesforce Administrators**

## Expected Outcome

The system is expected to:

- **Reduce manual work** through automation.
- **Improve response time** for customer support requests.
- **Enhance customer satisfaction** through efficient ticket management.
- Provide better **visibility into support operations** through reports and dashboards.

## Functional Overview

| **Area** | **Functionality** |
|---|---|
| Case Management | Create, update, and manage customer support cases |
| Ticket Tracking | Track case status and priority |
| Automation | Automate notifications using Salesforce Flows |
| Reporting | Generate reports for support analysis |
| User Interface | Provide a Lightning App for easy access |
| User Roles | Support Agents, Managers, and Administrators |
